# Modkey Mobile

> **Material 3 Expressive Android-клиент для разработчиков и владельцев софта на платформе [Modkey (mod.wtf)](https://mod.wtf).**

Приложение создано разработчиком **[lonxzsy](https://t.me/lonxzsy)** специально для пользователей и разработчиков Modkey, чтобы перенести всю мощь веб-панели управления лицензиями прямо в ваш смартфон.

Отдельная и огромная благодарность создателю и архитектору платформы **Modkey** — **[CATPON-dev](https://github.com/CATPON-dev)** за отличную платформу и функциональный API!

## Ключевые возможности

### 1. Авторизация и мульти-аккаунты
- **Вход по API-ключу**: мгновенный доступ по ключу из раздела `/admin/api`.
- **Вход по логину и паролю**: приложение автоматически логинится на сайте, получает CSRF/сессию и извлекает реальный API-ключ без необходимости вручную лезть в браузер.
- **Вход через Telegram / Web**: встроенный умный WebView с поддержкой Telegram OAuth виджета и перехватом копирования ключа.
- **Менеджер аккаунтов**: сохранение нескольких профилей и переключение между ними в 1 тап.

### 2. Дашборд софта в реальном времени
- **Счётчики ключей**: активные, на паузе, заблокированные, истекшие.
- **Аварийный тумблер (Emergency Switch)**: мгновенный перевод софта в режим техработ (`Offline`) с указанием причины или возврат в `Online`.
- **Быстрые массовые действия**: «Пауза всех ключей», «Возобновить все», «Продлить всем (+дни)», «Сбросить HWID всем».
- **Настройки софта**: смена шаблона генерации (`key_format`), лимитов HWID и переключение Test Connect.

### 3. Генератор и управление ключами
- **Шаблоны в 1 клик**: сохраняйте популярные конфигурации (например, «7 дней PUBG 1 устр.») и выпускайте ключи одним нажатием.
- **Массовая выдача**: выпуск от 1 до 50 ключей за раз (включая одноразовые `single`).
- **Быстрый шаринг**: кнопки «Скопировать» и «Поделиться» для мгновенной отправки ключа покупателю в Telegram/WhatsApp.
- **Массовая очистка (`delete-keys`)**: удаление истекших (`expired`), заблокированных (`blocked`) или неактивированных (`unused`) ключей для поддержания базы в чистоте.
- **Экспорт базы (`export-keys`)**: выгрузка ключей в `.txt`, `.csv` или `.json`.
- **Редактирование ключей**: переименование ключа (кастомное имя), сброс привязки HWID, блокировка и пауза.

### 4. Реселлеры и клиенты (Client Accounts)
- Просмотр списка с фильтрами («Реселлеры», «Админы», «Заблокированные»).
- Создание новых аккаунтов реселлеров прямо со смартфона.
- Управление балансом (`saldo`), быстрые кнопки пополнения (`+100`, `+500`, `+1000`, `+5000 ₽`).
- Мгновенная блокировка/разблокировка и сброс сессий (`kick-user-sessions`).

### 5. Зеркала и SSL-домены (Custom Domains)
- Управление кастомными доменами для защиты от блокировок (Let's Encrypt SSL).
- Мастер добавления домена с подсказками по DNS TXT-записи (`_modkey.<domain>`) и удобным копированием токена верификации.
- Включение, пауза и удаление зеркал.

### 6. Connect Тестер & Генератор клиентского кода
- **Тестер Connect**: проверка валидации лицензии и привязки Android HWID с расчётом и верификацией подписи `MD5(source_template)` при указании `CONNECT_SECRET`.
- **Генератор кода**: готовые к вставке сниппеты с проверкой токена на:
  - **Kotlin / Android (OkHttp)**
  - **C++ (libcurl)**
  - **C# (.NET HttpClient)**
  - **Python (requests)**
  - **cURL**

### 7. Виджет для рабочего стола Android
- Минималистичный Material 3 виджет на экран смартфона: отображает имя софта, статус сети (`Online`/`Offline`), число активных лицензий и кнопку аварийного переключения софта без открытия приложения.

## Дизайн и Архитектура

- **Архитектура**: 100% Kotlin, Jetpack Compose, Material 3 Expressive (M3E), Clean Architecture + MVVM.
- **Динамический цвет**: поддержка темы `PaletteStyle.Expressive`, адаптивных системных цветов Android 12+, тёмной и светлой темы.
- **Expressive Motion**: пружинные тактильные отклики (`Modifier.expressiveClick`) и анимации переходов.
- **Сетевой слой**: OkHttp 4 + KotlinX Serialization (работает с API v1, API v2 и Connect эндпоинтами).
- **Хранение данных**: Jetpack DataStore Preferences.

## Сборка проекта

### Требования
- Android Studio Ladybug / Meerkat (или новее)
- JDK 21
- Android SDK 35 (Android 15)
- Минимальная версия Android: 8.0 (API 26)

### Команды для сборки
```bash
git clone https://github.com/lonxzsy-dev/modkey-app.git
cd modkey-app

./gradlew assembleDebug

./gradlew assembleRelease
```
Готовый Release APK будет находиться в папке:
`app/build/outputs/apk/release/app-release.apk`

## Идеи для дальнейшей доработки (Roadmap)

Для тех, кто хочет развивать проект или контрибьютить:
1. **Push-уведомления через WebSocket/Telegram-бота**: оповещения на телефон при создании нового ключа реселлером или падении сервера.
2. **Оффлайн-кэширование через Room**: возможность просматривать базу ключей и реселлеров без активного интернет-соединения.
3. **Графики доходности и продаж**: визуализация статистики активаций ключей по дням и неделям (графики M3E).
4. **Биометрия (BiometricPrompt)**: вход в приложение по отпечатку пальца или Face Unlock для повышенной безопасности.
5. **Wear OS компаньон**: микро-приложение для часов для быстрого мониторинга статуса софта.
